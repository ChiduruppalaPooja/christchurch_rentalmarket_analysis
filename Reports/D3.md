## 1. Objective

Move from the no-code workflow (D2) to a reproducible R workflow covering several months of Airbnb data. The brief asked us to:

- download every `listings.csv` from October 2025 to June 2026;
- load one dataset into Python or R;
- filter to Christchurch only and use only this filtered data from then on;
- add a column for month + year;
- prepare every downloaded dataset in the same way and concatenate them into one Christchurch dataset covering October 2025 – June 2026;
- produce summary statistics for all columns (categories and counts, or min, max, mean and standard deviation) and the number of missing values per column;
- store the concatenated dataset in a new file; and
- reproduce the D2 no-code workflow and plots in R/Python.

## 2. What we achieved

- Nine monthly Inside Airbnb snapshots (October 2025 – June 2026) were loaded, filtered to Christchurch City, labelled with their month, and combined into **28,795 listing-month rows**.
- The combined data contains **4,117 distinct listing IDs** and **2,103 distinct host IDs**. 3,902 listings appear in more than one month, which is expected because each file is a monthly snapshot.
- Summary statistics, missing-value counts and frequency tables were generated by code and saved as CSV tables.
- The combined dataset was saved to `data/processed/`.

## 4. How we did it

### Step 1: Load one dataset (`R/01_airbnb_prepare.R`)

1. Read the June 2026 `listings.csv` into R and checked that the required columns were present.
2. Filtered to `neighbourhood_group == "Christchurch City"`. The script stops if no rows remain or if any non-Christchurch rows remain.
3. Added `snapshot_month = "June"` and `snapshot_year = 2026`. These identify the snapshot and are not based on `last_review`.
4. Inspected missing values, prices, minimum nights, duplicate IDs, categories, coordinates and numeric ranges, then saved the result.

Output: `data/processed/airbnb_christchurch_2026_06_clean.csv` (3,469 rows × 19 columns).

### Step 2: Prepare and combine all months (`R/02_airbnb_combine.R`, sections 1–6)

1. **Load:** built the expected file list from the configured study period (`R/pipeline_config.R`) and stopped if any monthly file was missing. Each file was read with `id` and `host_id` as **character**, because these very large IDs can lose precision if stored as numbers. The script stops on parsing errors or missing required columns.
2. **Check structure:** confirmed that all monthly files have identical columns before combining.
3. **Filter:** applied the same Christchurch City filter to every month, stopping if any month became empty or still contained other districts.
4. **Label:** added `month_year` (for example `2025_10`), taken from each source filename, and checked that every month carries the correct label.
5. **Combine:** stacked the months with `bind_rows()` and checked that the combined row count equals the sum of the monthly row counts and that all nine snapshots are present.
6. **Inspect:** reviewed the structure, summary statistics and missing values of the combined dataset. The findings fed into the cleaning decisions in D4.

The same script then applies the D4 cleaning and writes the dataset to file (see D4).

### Step 3: Summary statistics (`R/04_airbnb_summary.R`)

From the saved dataset, the script produces:

- missing-value counts and percentages for every column;
- count, missing, mean, median, min, max and standard deviation for every numeric column;
- the number of distinct values for each categorical column;
- frequency tables for room type, neighbourhood and month; and
- duplicate checks: duplicate IDs within a month, IDs repeated across months, and fully duplicated rows.

## 7. Limitations and open items

1. **Missing prices.** Prices are completely absent from the December 2025 – February 2026 source files, so any price analysis for those months has no data.
2. **Repeated listings are not duplicates.** The same listing appears in several months. Counts of rows are listing-months, not distinct properties.
3. **Combined and cleaned output share one file.** `02_airbnb_combine.R` writes only the cleaned dataset, so the summary statistics in `04` describe the cleaned 15-column dataset (see D4) rather than the raw concatenated data.

## 8. How to reproduce

With the nine monthly files in `data/raw/`, from the RStudio project root:
